A small, dependency-free numerical toolbox for JavaScript and TypeScript, caught at work. Six experiments you can touch. Every orbit, mode, crossing and basin on this page is computed in your browser by the library itself; nothing is pre-rendered.

Six small machines, one library.

numerics-js collects the classical building blocks of scientific computing: ODE solvers, quadrature, root finding, optimisation, interpolation, special functions and linear algebra, as typed, native-ESM modules that run in Node and in the browser.

These pages put them in motion. Each chamber below names the exact calls it uses, shows live statistics from the solver, and links back to the reference documentation.

01 · special

A drum that rings in Bessel zeros

Strike a circular membrane and it vibrates in modes shaped like Jn(jn,m r)·cos nθ. The zeros of the Bessel function fix every pitch, and they are not whole multiples of one another, which is why a drum sounds like a drum and a string like a string. 

import { special } from 'numerics-js';

const j = special.besselJZero(2, 1);   // 5.1356…
const u = (r, th) =>
  special.besselJ(2, j * r) * Math.cos(2 * th);
view

LineageBernoulli and Euler met these functions in vibrating chains and drums; Friedrich Bessel gave them their systematic theory in 1824, studying planetary perturbations. special in the API docs ↗

02 · ode

Gravity, kept honest

Velocity Verlet is a symplectic integrator: it does not make the energy error small so much as keep it bounded forever. That is why it runs planets for millions of steps without spiralling in or out. Drag on the sky to launch a body and watch the preview arc. 

import { ode } from 'numerics-js';

const step = ode.createVelocityVerlet(
  (u, v, a) => gravity(u, a)
);
step(state, 0.002);  // advances u, v, a in place
scene
launch

LineagePopularised by Loup Verlet's 1967 molecular-dynamics simulations of liquid argon, and the workhorse of N-body and particle codes ever since. The three-body figure-eight is the Chenciner–Montgomery orbit (2000). ode in the API docs ↗

03 · optimize

A triangle that feels its way downhill

Nelder–Mead needs no gradient, only function values. A simplex reflects, expands and contracts across the landscape until it collapses on a minimum. Himmelblau's function has four of them, so where you start decides where you end up. Click to release a simplex, or map every basin at once. 

import { optimize } from 'numerics-js';

const res = optimize.nelderMead(himmelblau, [-0.5, -0.3], {
  callback: (iter, simplex, fx) =>
    ({ stop: false, success: true }),
});

Click anywhere on the landscape to release a simplex.

LineageJohn Nelder and Roger Mead, 1965. The basin map above is thousands of independent searches, one per pixel. optimize in the API docs ↗

04 · four modules at once

Draw a curve, interrogate it

Move the knots and the shape-preserving PCHIP interpolant follows without a single overshoot. Four modules then question it at once: the slope under your cursor, the area between a and b, and every place the curve crosses the amber level. 

import { interpolate, integrate, numdiff, roots }
  from 'numerics-js';

const f = new interpolate.PchipInterpolator1D(xs, ys);
const area = integrate.quad((x) => f.eval(x), a, b);
const [slope] = numdiff.derivativeCentered(
  (x) => f.eval(x), x0);
const hit = roots.brent((x) => f.eval(x) - level, xl, xr);

LineageMonotone cubic interpolation (Fritsch & Carlson, 1980), adaptive Gauss–Kronrod quadrature (Kronrod, 1960s) and Brent's root finder (1973, after Dekker). interpolate in the API docs ↗

05 · linalg · ode

Every linear world, one square

A two-dimensional linear system is fully described by the trace and determinant of its matrix. Drag the puck in the small diagram and the flow rearranges itself: saddles, nodes, spirals, centres. The dashed lines are eigenvectors; cyan flows in, rose flows out. 

import { linalg, ode } from 'numerics-js';

const A = linalg.Matrix.from([[0, 1], [-det, trace]]);
const pairs = A.eig();   // eigenvalues and eigenvectors
ode.rungeKuttaFixed('rk4', rhs, 0, h, [x, y], h);
